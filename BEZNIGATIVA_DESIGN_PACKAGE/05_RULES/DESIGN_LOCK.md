# DESIGN LOCK — BEZNIGATIVA

## 1. Визуальная конституция
1. Основной фон — глубокий почти чёрный, не чистый `#000`.
2. Главный акцент — фиолетовый; вторичный — холодный cyan/blue.
3. Статусы: зелёный = онлайн/успешно; жёлтый = внимание/задача; красный = ошибка/отошёл/отклонено; фиолетовый = на созвоне/AI.
4. Главная метафора продукта — живой pixel office. Она не должна исчезать при переходе между экранами.
5. UI обязан оставаться профессиональным dashboard/workspace, а не превращаться в игру.
6. Pixel-art персонажи — акцент и навигационная метафора; не использовать их как случайные декоративные стикеры.

## 2. Типографика
- Основной UI: Inter.
- Альтернативный системный/табличный режим: Manrope, если технически целесообразно.
- H1 desktop: 32–40 px, 700.
- H2: 24–28 px, 650–700.
- H3: 18–20 px, 600.
- Body: 14–16 px, 400–500.
- Caption: 12–13 px.
- В одну строку не помещать больше информации, чем пользователь может быстро просканировать.

## 3. Сетка
Desktop:
- 12 колонок.
- Максимальная ширина контента 1440 px.
- Рабочий gutter 24 px.
- Межкарточный gap 16 px.
- Минимальный внутренний padding стандартной карточки 16 px.
- Sidebar: 248–280 px, sticky/fixed.

Tablet:
- 8 колонок.
- Gutter 20 px.
- Sidebar collapsible.

Mobile:
- 4 колонки.
- Gutter 16 px.
- Bottom navigation / compact top navigation.
- Основные карточки становятся вертикальными.

## 4. Glass
Использовать:
- translucent surface 3–7% white overlay;
- border 6–12% white;
- blur 18–28 px;
- мягкая внешняя подсветка только для активных/важных поверхностей.

Запрещено:
- стекло на каждом элементе;
- сильный blur за текстом;
- нечитаемые панели из-за прозрачности;
- градиентная радуга;
- неоновые тени вокруг всего интерфейса.

## 5. Layout
Каждая страница должна иметь:
- ясный заголовок;
- primary action;
- контекст/фильтры;
- main workspace;
- понятную иерархию;
- responsive fallback.

Никаких экранов, где пользователь видит 5–8 равнозначных CTA.

## 6. Pixel Office
Pixel Office может занимать hero/workspace-панель на dashboard и отдельный экран.
- isometric camera;
- ограниченное количество активных NPC;
- понятные зоны;
- персонажи имеют state: `offline`, `online`, `working`, `call`, `away`, `break`, `task`;
- персонаж должен быть связан с реальным пользователем/сотрудником;
- клик по персонажу открывает компактную profile popover.

## 7. Запрет на отклонение
Агенту запрещено:
- заменять pixel office на 3D realistic style;
- делать светлую тему по умолчанию;
- менять русский язык на английский;
- использовать другой sidebar без явной причины;
- добавлять произвольные разделы;
- выбрасывать realtime;
- делать страницу без loading/error/empty states;
- превращать продукт в обычный CRUD без визуальной иерархии;
- заменять персонажей плоскими generic avatars без причины;
- грузить все пиксельные ассеты на каждой странице.
