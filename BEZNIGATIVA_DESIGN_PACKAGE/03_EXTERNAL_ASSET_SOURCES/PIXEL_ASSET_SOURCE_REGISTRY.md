# BEZNIGATIVA — Pixel Asset Source Registry

Purpose: vetted sources for pixel UI, characters, environment, isometric material, furniture and decorative assets.

IMPORTANT: these are source/reference packs. They are NOT instructions to mix visual styles blindly. The final BEZNIGATIVA visual language remains the source of truth in `DESIGN_LOCK.md` and the storyboard references.

## 3. Source-selection policy

Use CC0 sources first for generic base material. For any asset with a non-CC0 license, the agent MUST record the license and attribution requirements before using it.

Do not download random "free pixel art" from Pinterest, image aggregators, Discord attachments, or unverified reposts.

Do not scrape copyrighted game assets.

Do not use trademarked character likenesses or branded game art as production assets.

Do not mix a 16x16 retro RPG source, a glossy 3D source and a modern pixel source in the same scene unless the composition deliberately treats them as separate layers and the Design Lock allows it.

## 4. BEZNIGATIVA visual authority

External sources are subordinate to:
1. BEZNIGATIVA storyboard images.
2. `DESIGN_LOCK.md`.
3. `BEZNIGATIVA_DESIGN_SPEC_v1.md`.
4. This registry.

When a source conflicts with our visual language, do not follow the source; adapt or replace it.
