# BEZNIGATIVA — Pixel Assets Pack / подготовка к импорту

## Важно
Представленные изображения в этой папке — **визуальные референсы / preview asset sheets** текущей серии генераций. Они НЕ являются финальными отдельными PNG-ассетами каждого объекта.

Для production-версии каждый объект нужно выпускать отдельным файлом с прозрачным фоном:

- 1 персонаж = 1 PNG
- 1 поза/состояние = 1 PNG либо отдельный кадр по согласованному animation pipeline
- 1 предмет = 1 PNG
- 1 мебель = 1 PNG
- 1 декоративный элемент = 1 PNG
- 1 иконка = 1 PNG/SVG по назначению
- 1 комната/сцена = отдельный background/scene asset

## Требования для финальных ассетов

- PNG с прозрачным фоном, если это объект/персонаж/иконка.
- Единый pixel-art стиль.
- Единая камера и перспектива для изометрических объектов.
- Единый масштаб и базовая высота персонажей.
- Никаких подписей, рамок и UI поверх самого ассета.
- Никаких посторонних объектов внутри изображения.
- Сохранять пропорции и читаемость силуэта.
- Имена файлов должны быть предсказуемыми и стабильными.

## Запрет для агента-разработчика

Не использовать composite/sprite-sheet изображения как production-источники, если существует отдельный asset.

Не вырезать персонажей или предметы из preview sheet автоматически без явного задания.

Не менять визуальный стиль ассетов самостоятельно.

Не смешивать разные размеры, перспективы и pixel-density.

## Animation set персонажа

Базовый набор рекомендуется делать таким:

`idle` → `walk_01..04` → `sit` → `work` → `talk` → `phone` → `think` → `celebrate` → `sleep` → `away`

Система офиса может использовать эти состояния для визуального realtime-статуса сотрудника: на месте, работает, на созвоне, отошёл, не в сети.

## Для GLM

Preview sheets можно использовать только как референс композиции и стиля.

Финальный код должен работать с атомарными ассетами из каталогов, а не с необходимостью самостоятельно резать большие изображения.
