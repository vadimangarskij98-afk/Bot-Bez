# BEZNIGATIVA — PROJECT CONTEXT

## Назначение архива
Этот архив содержит текущее ТЗ проекта, документацию по визуальным ассетам и все сгенерированные reference-изображения, использованные для формирования визуального направления.

## Концепция продукта
BEZNIGATIVA — платформа для работы с блогерами, музыкантами, артистами и внутренним персоналом.

Ключевой принцип:
Telegram → заявка/коммуникация → веб-кабинет → команда → задачи/проекты → контент/документы → realtime-синхронизация.

## Визуальное направление
- Dark / Black Liquid Glass для web-интерфейса.
- Пиксельный изометрический офис как живой 3D/2.5D слой.
- Pixel-art персонажи представляют сотрудников, блогеров, музыкантов и другие роли.
- Статусы сотрудника должны отражаться и в интерфейсе, и в сцене офиса.
- В дальнейшем персонажи и объекты должны использоваться как отдельные атомарные PNG-ассеты, а не как один composite sprite sheet.

## Принцип атомарных ассетов
Один визуальный объект = один файл.

Примеры:
- admin/idle.png
- admin/walk_01.png
- blogger/work.png
- musician/guitar.png
- desk_01.png
- camera_01.png
- room_reception.png

## Важное ограничение для AI-разработчика
Reference sheets в этом архиве предназначены для визуального референса. Нельзя использовать их как готовые игровые ассеты и автоматически вырезать из них элементы с потерей качества.

Финальный production-пак должен состоять из отдельных файлов с прозрачным фоном и единым масштабом/камерой.

## Архитектурная идея
- Next.js 16 + TypeScript
- PostgreSQL / Supabase
- Telegram Bot API
- Telegram Mini App
- Realtime / WebSocket layer
- Object Storage
- RBAC / RLS
- AI agents с controlled tools
- Notifications / event-driven architecture

## Главное требование
Не строить продукт как простой Telegram-бот или CRM. Это единая Creator & Production Operating System, где Telegram является каналом взаимодействия, Web App — рабочей средой, а Pixel Office — живым визуальным представлением состояния команды.
