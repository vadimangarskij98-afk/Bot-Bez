# BEZNIGATIVA — Design Storyboard Package

Эта папка содержит визуальную раскадровку и техническую дизайн-спецификацию платформы BEZNIGATIVA.

## Как использовать

1. Сначала прочитать `BEZNIGATIVA_TZ_v1.md`.
2. Затем прочитать `BEZNIGATIVA_DESIGN_SPEC_v1.md`.
3. Сверять реализацию с `01_STORYBOARD/`.
4. Использовать `02_REFERENCES/` как исходный визуальный direction для pixel office и ассетов.
5. Не использовать composite reference sheets как производственные PNG-ассеты.

## Основные экраны в storyboard

01. Авторизация / Telegram
02. Главная / Dashboard / Pixel Office
03. Система заявок
04. Карточка кандидата / участника
05. Кабинет участника
06. Задачи
07. Команда / сотрудники
08. Чат / коммуникации
09. Календарь
10. База знаний
11. Аналитика
12. Финансы
13. Настройки
14. Mobile Web App / Telegram Mini App
15. Telegram Bot flows
16. Pixel Office / Locations

## Важное

Storyboard — визуальная спецификация, а не набор production PNG. Production assets должны храниться отдельно: один объект = один PNG с прозрачным фоном, по правилам `BEZNIGATIVA_ASSETS_README.md`.
